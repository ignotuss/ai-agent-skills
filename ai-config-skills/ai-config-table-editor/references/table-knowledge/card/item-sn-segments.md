## sn 的顺序语义：sn 就是展示顺序

以下表的 `sn` 不只是主键，**直接决定玩家看到的顺序**，重排 sn 属于可见变更：

- `MidAutumnShop.sn` —— 中秋商店的展示顺序（2026-09-23 重排过 sn7~sn9）
- `RankActivityBanner.sn` —— 首页 banner 的展示顺序
- `Shop.sn` —— 商城列表顺序（同 rewardId 可以有多条，靠 sn 区分）

**改这些表的 sn 时必须在回报里明确提示"这是玩家可见的顺序变化"，不要当成纯数据整理。**
